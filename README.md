# IoShim
Software adapter for various bemanitools I/O dlls. (currently supports SDVXIO and IIDXIO)
Has support for keyboard/gamepad/mouse output.

##

For gamepad output, you will need to install [ViGEmBus](https://github.com/ViGEm/ViGEmBus/releases/latest) for it to work.   
For DirectInput keyboard emulation, you will need to install [Interception](https://github.com/oblitum/Interception) and run the app as Admin for it to work.

More game I/O support coming soon
